# pan_for_lang

Программа для Windows 10/11 и перьевого дисплея **XPPen Artist 12 Pro**, которая учит русскоязычного ребёнка 8–10 лет писать по-английски **прописью** (американский cursive в стиле Zaner-Bloser): строчные и заглавные буквы, соединения, слова и короткие предложения под диктовку — с переносом навыка на бумагу.

Статус: **проектирование завершено, начинается веха v0 (минимальная работающая вертикаль)**.

## Ключевые решения

- Конечная цель — беглое английское слитное письмо; печатные буквы нужны для чтения («прочитал или услышал → написал прописью»).
- Стиль — американская пропись (Zaner-Bloser); стили письма подключаются пакетами данных.
- Произношение — американское (GA). Интерфейс RU/EN.
- Офлайн, все данные локально; сырые траектории пера сохраняются только с согласия родителя.
