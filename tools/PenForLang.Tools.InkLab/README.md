# InkLab — запись, повтор и разметка (V0.9)

Инструмент разработчика (WPF, `tools/PenForLang.Tools.InkLab`, в установку не входит). Одно окно, четыре вкладки:
**Запись**, **Повтор**, **Разметка**, **Сводка**. Вкладки «Зонд», «Глифы», «Эксперт», «Разбор» из ARCHITECTURE.md §2.2 появятся позже.

## Запуск

| Как | Что получится |
|---|---|
| `6-inklab.cmd` в папке пакета V0 (`build\publish-v0.cmd` кладёт InkLab рядом с программой) | перо через `WM_POINTER`, окно на мониторе пера |
| `6-inklab.cmd --mouse` | мышь как перо (работа без планшета; такие записи в корпус эталонов не годятся — в сводке они помечаются) |
| `dotnet run --project tools/PenForLang.Tools.InkLab -- --mouse` | то же из исходников |

Параметры: `--mouse`, `--corpus-dir <папка>` (корпус; по умолчанию `%LOCALAPPDATA%\PenForLang\corpus`), `--content-dir <папка>`,
`--monitor <N>`, `--xheight-mm <мм>` (по умолчанию 15), `--subject <id>`, `--annotator <id>` (идентификатор разметчика сеанса; по умолчанию `A`),
`--exit-after <сек>`. При сбое интерфейса сообщение показывается в окне, подробности — в `%LOCALAPPDATA%\PenForLang\inklab-crash.log`.

## Как записывать (для взрослых)

1. Откройте вкладку **Запись**. Введите **идентификатор субъекта** (например `adult-1`; имя не нужно), отметьте «левша», если пишете левой.
   Возраст и номер согласия — по желанию (взрослому согласие не нужно). Нажмите **«Начать / продолжить»**.
   У субъекта с сохранённым прогрессом рука, возраст и согласие берутся из прогресса (в записях они должны совпадать).
2. Протокол (вариант B, 120 подсказок): буквы `a`, `i`, `t` по 30 раз, затем слова — **`at` с отрывом** ×10, **`at` слитно** ×10, **`it` с точкой** ×10.
   Слева на холсте анимируется эталон (слово — из глифов букв); **пишите справа, копируя его**, в обычном темпе, аккуратно. Указание — над холстом:
   - `at` с отрывом: «напишите a с выходным штрихом до линии, оторвите перо, начните t с верха подъёма; перекладину — после слова»;
   - `at` слитно: «соединение a→t одним движением; перекладину — после слова»;
   - `it` с точкой: «напишите i, оторвите перо, сразу поставьте точку, вернитесь и соединением продолжите t; перекладину — после слова».
3. Кнопки:
   - **Готово** — попытка сохраняется отдельным файлом, показывается следующая подсказка;
   - **Заново** — холст очищается, попытка продолжается (в записи останется только последняя версия); работает, когда перо поднято;
   - **Пропустить** — подсказка помечается пропущенной (к ней можно вернуться из списка слева двойным щелчком);
   - **Назад** — предыдущая подсказка; если записать её заново, прежняя запись уйдёт в подпапку `superseded`;
   - **Показать эталон** — анимация ещё раз.
4. Закрыть окно можно в любой момент: прогресс хранится в `progress.json` (с копией `progress.json.bak`). При следующем запуске с тем же идентификатором запись
   продолжится с места остановки; программа сверяет прогресс с файлами записей по заголовкам: потерянный или повреждённый прогресс восстанавливается, дубли
   одной подсказки уходят в `superseded`.
5. Не меняйте размер окна во время попытки: линейка фиксируется на первом касании; если она изменилась, «Готово» откажет — нажмите «Заново».

Записи лежат в `<корпус>\<субъект>\<подсказка>-<дата-время>.pfl.jsonl.gz` (формат `pfl.penlog/1`, ARCHITECTURE.md §3.4; в заголовке:
`task` — что просили написать (`taskId = inklab-v0.9/<подсказка>`), `subject` — взрослый без имени, линейка, экран, устройство). Вариант написания записан
в событиях `prompt` (в самом начале попытки) и `stimulus-start`; поля `task.variant` в формате penlog нет. Точки наведения не пишутся. Запись, прогресс и
файлы разметки пишутся атомарно (временный файл, сброс на диск, переименование).

## Повтор

Вкладка **Повтор**: «Папка…» (или «Файл…») → выберите запись → **Играть**. Воспроизведение идёт через `ReplayPenSource` в реальном времени или
ускоренно (0,5×…8×), «Показать всё» рисует попытку целиком. След — поверх линеек в x-height; «Заново» стирает холст, как у пишущего. Ниже — метаданные записи.

## Как размечать

Вкладка **Разметка**: «Папка…» → выберите запись (в списке видно, размечена ли она, и дубли заданий). **Разметчик** — идентификатор сеанса (`--annotator` или поле над
следом): от него зависит имя файла, и он **не берётся из загруженного файла**. Чужие разметки той же записи только читаются (список «Другие разметчики»).
Порядок работы с записью:

1. **Что написано** — буквы по порядку без пробелов (по умолчанию — цель задания, например `at`). Если написано не то, исправьте и поставьте флаг «написано не то».
2. **Сначала отложенные штрихи** (точка `i`, перекладина `t`). Инструмент «Отложенные штрихи» (Ctrl+D переключает инструмент), выберите букву, кликните по штриху;
   повторный клик снимает отметку. Отложенные штрихи не входят в основной след. Время («сразу» / «после слова») **выводится из порядка штрихов**; «⇄» записывает ваше
   мнение, если оно другое (программа предупредит о расхождении). Для `i`, `j`, `t`, `f` без отложенного штриха и для неподходящего вида — предупреждения.
   Если стык стоял на штрихе, который стал отложенным, он сбрасывается.
3. **Потом границы букв.** Для каждого стыка (`a|t`) **два клика по следу**: первый — **выход** левой буквы (где кончается её тело, exit глифа), второй — **вход** правой
   (где начинается тело, entry глифа; у `t` — верх подъёма). Участок между ними — соединительный штрих. **Shift+клик** — граница одной точкой (вход = выход).
   Допустимы только точки в порядке вдоль следа между соседними стыками. Стрелки **←/→** сдвигают последнюю поставленную точку на одну точку записи.
   Вид стыка вы не выбираете, он следует из штрихов: **«соединены»** — выход и вход в одном штрихе, **«отрыв пера»** — в разных (точки могут стоять где угодно в своих штрихах,
   между ними нет основных штрихов). «Уверенность» стыка (высокая / средняя / низкая) — по кругу кнопкой.
4. **Качество**: «годится» или брак (снимите галочку), флаги и заметка.
5. **Сохранить** (Ctrl+S). Справа — проверка: границы идут по порядку, стыков ровно «букв − 1», точки и их время совпадают с записью, хеш записи тот же и т. д.
   Неполная разметка сохраняется как черновик (в списке — «начато, ошибок: N»). При переходе к другой записи и перед «Обновить» несохранённое сохраняется;
   **если сохранить не удалось, переход отменяется**. Ctrl+N — к записи, не размеченной этим разметчиком; Ctrl+←/→ — соседние записи.

### Формат файла разметки `pfl.annotation/1`

Файл `<имя записи>.pfl.jsonl.gz.ann.<разметчик>.json` лежит рядом с записью (идентификатор разметчика очищается, как имя папки: недопустимые символы → `_`).
Файл прежнего вида `<запись>.ann.json` читается как файл автора, названного внутри. JSON Schema — `schemas/pfl.annotation.v1.schema.json` (там же полное описание соглашений);
проверка — `AnnotationValidator` (коды замечаний — `IssueCodes`); чтение выбирает разбор по `schema`, неизвестные поля и другие версии — ошибка.

```json
{
  "schema": "pfl.annotation/1",
  "penlog": "at-lift-001-20261014-120000.pfl.jsonl.gz",
  "penlogSha256": "0123…cdef",
  "indexing": "inkattempt-after-last-restart",
  "target": "word:at",
  "variant": "lift",
  "annotator": "A",
  "annotatedAt": "2026-10-14T12:00:00Z",
  "tool": "InkLab",
  "text": "at",
  "quality": { "usable": true, "flags": [] },
  "strokes": [ { "n": 21, "t0": 0, "t1": 100000 }, { "n": 21, "t0": 200000, "t1": 300000 }, { "n": 11, "t0": 500000, "t1": 550000 } ],
  "junctions": [
    { "after": 0, "kind": "lifted",
      "end":   { "stroke": 0, "sample": 19, "t": 95000 },
      "start": { "stroke": 1, "sample": 0,  "t": 200000 },
      "confidence": "high" }
  ],
  "deferred": [ { "stroke": 2, "letter": 1, "kind": "crossbar", "timing": "afterWord" } ]
}
```

- **Привязка к записи:** `penlogSha256` — SHA-256 несжатого JSONL; `strokes` — число точек и времена первой и последней точки каждого штриха; `t` у точек — `PenSample.TimeUs`
  (мкс от начала задания). Валидатор сверяет всё; изменённая запись даёт ошибки `hash-mismatch`, `stroke-mismatch`, `point-time`.
- **Нумерация** (`indexing`): штрихи и точки — как в `PenLog.ToInkAttempt()` по умолчанию, то есть **только штрихи после последнего «Заново»**, с 0; внутри штриха — точки контакта по порядку.
- `text` — что фактически написано; букв `n = длина text`. `junctions` — ровно `n − 1` стыков: `after` — между буквами `after` и `after + 1`; `end` — выход тела левой буквы,
  `start` — вход тела правой; `end = start`, если отдельного соединения нет; `kind`: `connected` (один штрих) или `lifted` (между ними отрыв пера основного следа).
  Тело буквы `k` — от `start` стыка `k−1` (для первой — от начала основного следа) до `end` стыка `k` (для последней — до конца основного следа).
- `deferred` — отложенные штрихи: `letter` (с 0), `kind` (`dot`, `crossbar`, `other`), `timing` — **выведенное** из порядка штрихов время (`immediate`, если после штриха пишется основной штрих; иначе `afterWord`);
  необязательное `timingOpinion` — мнение разметчика, только если оно отличается.
- `quality.usable` — годится/брак; `flags`: `wrongContent`, `corrected`, `hesitation`, `outOfGuides`, `deviceGlitch`, `other`. Для брака стыки не обязательны.
- Основной след — все штрихи, кроме отложенных.

## Сводка

Вкладка **Сводка** → «Обновить сводку»: сколько записей по видам (`glyph:a`, `word:at · lift`, `word:at · joined`, `word:it · dot`…), по субъектам и по **источнику пера**, сколько
размечено верно (лучшее среди разметчиков), сколько брака, начато и без разметки. **Предупреждения:** записи мышью (`Mouse` — пробные, не для корпуса), дубли `taskId`
у одного субъекта, нечитаемые файлы. «Сохранить» кладёт `corpus-summary.md` в корень корпуса.

## Для разработчика

- ViewModel (`ViewModels/`), протокол (`Protocol/`), корпус (`Corpus/`), разметка (`Annotation/`), сцена для рисования (`Scene/`) не зависят от окна;
  тесты — `tests/PenForLang.Tools.InkLab.Tests`. Окно (`MainWindow`, `Views/`) только связывает слои и источник пера.
- Эталон слова — временный: из изолированных глифов; после V0.10 (`WordTemplateBuilder`) его заменит настоящий шаблон с соединениями.
- `build\publish-v0.cmd` публикует InkLab во временную папку и сливает её в пакет через `build\merge-publish.ps1`; пересекающиеся файлы должны совпадать побайтно, иначе сборка пакета останавливается.
